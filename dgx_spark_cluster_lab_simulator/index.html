Repo review: 7 things to fix in the README
  1. DGX-04 netplan uses enP2p1s0f1np1 with 192.168.101.23; the topology says enP2p1s0f0np0 with .13. Fault 1 reproduces it.
  2. "AllReduce 2 Nodes" runs all_gather_perf.
  3. "ReduceScatter 2 Nodes" runs alltoall_perf.
  4. RDMA MTU note says ">4096"; it means below 4096. A 1500-byte netdev shows active_mtu 1024 (3), not "1500 (5)".
  5. The ib_write_bw server and client are both labelled DGX-04.
  6. NCCL_IB_GID_INDEX=3 is in the variables table but not in the Stable Configuration exports.
  7. nccl-tests is cloned inside ~/nccl, but the runs call $HOME/nccl-tests/build. Clone it in the home directory.
